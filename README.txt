個人家計簿 クラウド版
1. Supabase Authentication > Users > Add user > Create new user で自分のメール・パスワードを登録（Auto Confirm Userを有効）。
2. Authentication > Sign In / Providers で新規登録を無効にする。
3. index.html, style.css, app.js をGitHubリポジトリ直下にアップロード。
4. Settings > Pages > Deploy from a branch > main / (root) > Save。
5. 公開URLでログインし、登録・再読み込み・別端末での表示を確認。
ローカル試用版のデータは自動移行しません。公開用キーのみ使用。秘密鍵は登録しないでください。
